# AfriTalent

AfriTalent est un site vitrine responsive pour une plateforme qui connecte des freelances tech africains avec des entreprises a la recherche de competences fiables.

## Site en ligne

Le site est deploye avec GitHub Pages :

[https://ttdiane1703.github.io/afritalent/](https://ttdiane1703.github.io/afritalent/)

## Capture d'ecran

![Capture d'ecran du site AfriTalent](images/screenshot-afritalent.png)

## Pages disponibles

- Accueil : `index.html`
- Freelances : `freelances.html`
- Tarifs : `tarifs.html`
- A propos : `about.html`
- Blog : `blog.html`
- Contact : `contact.html`

## Fonctionnalites

- Navigation responsive avec Bootstrap.
- Hero visuel avec image principale.
- Mode sombre avec sauvegarde dans `localStorage`.
- Animations au scroll et compteurs animes.
- Filtres interactifs sur la page freelances.
- Validation JavaScript du formulaire de contact.
- Images locales optimisees pour les sections equipe, blog, freelances et temoignages.

## Technologies utilisees

- HTML5
- CSS3
- JavaScript
- Bootstrap 5
- Bootstrap Icons
